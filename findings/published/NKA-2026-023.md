## Preconditions

- make/cargo-built image (the nix path writes its own ceiling per profile; which path made the v0.9.3.5 artefacts was not checked)

## Description

The committed ceiling 0x1fdfffff7d refuses bits 40-43 (UserFiles, AcpiOwner, PolicyPush, PowerControl) that four capsules declare, and admits bit 9 (Admin) that none declares. The check script exits 1 and is wired into no makefile, nix file or workflow. A missing, short or zero ceiling file reads back as unrestricted (value.rs:39-47).

## Impact

Fails closed for four capsules on a make-built image; one spare capability bit admitted. A staging mistake weakens the ceiling instead of failing the build. No privilege gain found.

## Attack scenario

1. Build with make from the tag.
2. preflight refuses the four capsules whose caps leave the ceiling.

## Evidence

Reproduced: yes.

- Script run twice, independently: exit 1 with the two messages above; catalogue (170 entries) and 168 manifests compared.
- NOT run: make build or boot.

## Remediation

Regenerate the committed ceiling from the catalogue in CI and make the check blocking; treat a missing or zero ceiling as a build error for release profiles.
